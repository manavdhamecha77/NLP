# Assignment 2 - Text Segmentation

This project implements two text segmentation techniques for a Brown corpus sample stored in `text_segmentation_dataset.json`.

## Techniques Used

- Greedy longest-match segmentation
- Dynamic programming segmentation based on word log probability
- Accuracy evaluation
- Edit distance evaluation

## Files

- `main.py` - Runs the segmentation and evaluation pipeline.
- `Problem.txt` - Problem statement for the assignment.
- `text_segmentation_dataset.json` - Input dataset.
- `text_segmentation_metrics.json` - Saved evaluation metrics.
- `text_segmentation_predictions.json` - Saved model predictions.

## Running the Project

```bash
python main.py
```
