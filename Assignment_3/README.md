# Assignment 3 - DFA and FST

This project implements a DFA for basic English word checking and an FST for noun analysis using a Brown corpus noun lexicon.

## Techniques Used

- DFA-based word validation
- FST-based noun analysis
- Lexicon loading
- Transition table display

## Files

- `main.py` - Menu-driven entry point for the DFA and FST tasks.
- `dfa.py` - Implements the DFA logic for checking words.
- `fst.py` - Implements the FST logic for noun analysis.
- `brown_nouns.txt` - Noun lexicon used by the FST.
- `implement.txt` - Notes describing the FST logic.

## Running the Project

```bash
python main.py
```
